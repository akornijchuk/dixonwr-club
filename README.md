# DixonWR CRM — многостраничная версия

## Что есть
- Левое меню и отдельные страницы: главная, клиенты, добавление клиента, карточка клиента, редактирование и заглушка заказов.
- SQLite: таблица `customers` и существующие уникальные ограничения для телефона и Instagram.
- Сохранены API-маршруты создания, поиска, просмотра, списка и редактирования клиентов.
- Поиск, сортировка и пагинация списка клиентов.
- Docker сохраняет базу в `./data`.

## Как применить
1. Сделай резервную копию текущего файла `data/dixonwr.db`.
2. Останови приложение: `docker compose down`.
3. Скопируй файлы из этого проекта в папку текущего проекта, заменяя `main.py`, `Dockerfile`, `compose.yaml`, `requirements.txt` и добавляя папки `templates` и `static`.
4. **Не удаляй и не заменяй папку `data`** — в ней находится текущая база.
5. Запусти в PowerShell из папки проекта: `docker compose up -d --build`.
6. Открой `http://localhost:8000` и проверь страницы.

## Примечание по базе
В Docker приложение использует `/app/data`, смонтированную из локальной папки `./data`. При запуске Python вне Docker будет использовать `data/` внутри папки проекта.
